# Responsive Rules

## Breakpoint Baseline
- Mobile: < 768 px
- Tablet: 768-1023 px
- Desktop: >= 1024 px

## Layout Rules
- Mobile: single column, section ditumpuk vertikal.
- Tablet: dua kolom terbatas untuk panel sekunder.
- Desktop: multi-panel dengan hierarchy jelas.

## Spacing Rules
- Mobile: gunakan spacing lebih rapat namun tetap lega.
- Desktop: tambah ruang antar section untuk keterbacaan.

## Typography Rules
- Turunkan heading 1 tingkat di mobile jika terlalu dominan.
- Pertahankan minimum ukuran body teks agar tetap terbaca.

## Interaction Rules
- Komponen interaktif menyesuaikan touch target di mobile.
- Hindari hover-only interaction untuk fungsi penting.

## Prioritas Konten
- Tampilkan CTA utama lebih awal di mobile.
- Konten sekunder bisa dipindah ke collapsible section.
