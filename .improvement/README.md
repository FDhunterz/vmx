# VMX UI/UX Improvement Workspace

Folder ini berisi sumber acuan untuk "melatih" kualitas UI/UX modern secara konsisten di project VMX.

## Cara Pakai
- Isi dan update file-file di folder ini sebelum meminta redesign besar.
- Saat meminta perubahan UI, referensikan file yang relevan (misalnya token, komponen, atau UX rules).
- Jagakan isi tetap ringkas, konkret, dan bisa dieksekusi.

## File Utama
- `brand-guidelines.md`: identitas visual, tone, dan anti-pattern.
- `design-tokens.json`: token warna, spacing, radius, shadow, typografi, motion.
- `inspiration.md`: referensi visual dan alasan desain.
- `page-priorities.md`: urutan halaman/fitur yang diprioritaskan.
- `component-specs.md`: kontrak desain per komponen beserta state.
- `ux-rules.md`: aturan interaksi, validasi, feedback, dan alur kritikal.
- `content-guidelines.md`: aturan copywriting UI.
- `accessibility-checklist.md`: daftar cek aksesibilitas minimum.
- `responsive-rules.md`: perilaku antarmuka lintas breakpoint.

## Update Policy
- Jika ada keputusan desain baru, update file yang relevan lebih dulu.
- Hindari keputusan visual ad-hoc di komponen tanpa mencatatnya di sini.
