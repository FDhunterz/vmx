# Content Guidelines (UI Copy)

## Prinsip Umum
- Singkat, jelas, dan berorientasi aksi.
- Hindari jargon teknis jika bukan untuk user teknis.
- Konsisten istilah di seluruh aplikasi.

## Komponen Copy
- Title: 3-7 kata, langsung ke tujuan.
- Subtitle/helper: satu kalimat pendek untuk konteks.
- CTA primer: kata kerja + objek (`Generate Video`, `Start Upload`).
- CTA sekunder: netral (`Cancel`, `Back`, `Not Now`).

## Error Copy
- Format: masalah + solusi singkat.
- Contoh: `Webhook URL tidak valid. Pastikan menggunakan format http:// atau https://`.

## Success Copy
- Jelaskan apa yang berhasil dan apa langkah lanjutnya.
- Contoh: `Template berhasil disimpan. Anda bisa lanjut ke proses render.`

## Tone
- Profesional, hangat, dan tidak menggurui.
- Hindari ALL CAPS pada teks UI reguler.
